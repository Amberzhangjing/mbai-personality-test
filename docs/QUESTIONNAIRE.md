# MBAI questionnaire map

The canonical bilingual question text and scoring vectors live in `data/mbai-data.js`. This document describes the coverage plan without duplicating every answer weight.

| IDs | Primary axis | Scenario themes |
| --- | --- | --- |
| Q01, Q06, Q11, Q16, Q21, Q26 | D/C — AI agency | onboarding, prompt repair, disagreement, assistant design, iteration, ideal collaborator |
| Q02, Q07, Q12, Q17, Q22, Q27 | F/I — trust mode | source checking, decisions, habits, claims, model news, learning |
| Q03, Q08, Q13, Q18, Q23, Q28 | P/S — adoption tempo | model releases, unfamiliar tasks, team pilots, tool stacks, job change, sharing workflows |
| Q04, Q09, Q14, Q19, Q24, Q29 | O/G — digital boundary | prompt sharing, customer data, conversation history, knowledge bases, private advice, policy |
| Q05, Q10, Q15, Q20, Q25, Q30 | T/U — output standard | AI voice, generic imagery, templates, polishing, selection, brand voice |

## Writing rule

Every scenario should force a trade-off between two defensible behaviors. A question should not make one choice sound obviously more intelligent, ethical, modern, creative, or socially desirable.
