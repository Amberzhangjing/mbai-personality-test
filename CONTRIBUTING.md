# Contributing to MBAI

Thanks for helping make the test clearer, fairer, and more culturally useful.

## Good contributions

- scenarios that feel real without revealing the measured axis
- natural Chinese or English rewrites that preserve the same decision tension
- accessibility and mobile interaction improvements
- scoring changes supported by simulation results
- corrections to result copy that keep both poles valuable
- test cases for browsers, data integrity, and share-card output

## Content principles

1. Do not copy questions, descriptions, images, or distinctive visual assets from another personality test.
2. Do not frame one pole as intelligent, modern, moral, creative, or professionally superior.
3. Keep the Taste axis about intervention priority, not “good taste versus bad taste.”
4. Avoid diagnostic, clinical, hiring, or deterministic claims.
5. Chinese and English may be culturally adapted; they do not need to be literal translations, but they must test the same choice.

## Pull requests

Run `npm test` before submitting. Explain which questions, axes, or result types are affected and why. If weights change, include the new distribution summary.

By contributing, you confirm that you have the right to submit the work and agree to license code under MIT and assessment content under CC BY 4.0, as applicable.
